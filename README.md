# Aplikasi Jasa AC - Modern UI

## Menjalankan aplikasi

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Buka `http://127.0.0.1:5000` setelah server berjalan.

Login awal: `admin` / `admin`.

Virtual environment, database lokal, upload, cache Python, dan file rahasia diabaikan oleh Git melalui `.gitignore`.
